## 2. 文面（依頼書 §2 のとおり）

合図のある朝（`CONDITION_MET`・`REFERENCE_UNCONFIRMED`）だけ、比率を 2 か所に出す。D=2026-01-09 の試験データでの実出力（1 行目、2 行目、3 行目）：

```
【SOXL日次】対象D=2026-01-09 ／ 投入比率：利用可能資金の100%
【SOXL日次・ローカルプレビュー（実送信なし）】 対象D=2026-01-09 ／実行区分: 市場条件成立（確認済み）
▶ 投入比率：**利用可能資金の100%**（極端恐怖・確認済み、比率のみ）
```

| 種類 | 1 行目の後ろ | 本文の行 |
|---|---|---|
| 確認済み・極端恐怖／通常買い | `投入比率：利用可能資金の100%` | `▶ 投入比率：**利用可能資金の100%**（極端恐怖・確認済み、比率のみ）`（通常買いは「通常買い」） |
| 確認済み・トレンド参加 | `投入比率：利用可能資金の25%（手元確認が必要）` | `▶ 投入比率：**利用可能資金の25%**（トレンド参加・確認済み、比率のみ。0株か再参加かは手元確認）` |
| 参考・未確認 | `投入比率の目安：利用可能資金の100%（参考・未確認）` | `▶ 投入比率の目安：利用可能資金の100%（参考・未確認、比率のみ）`（太字なし） |

数は `rule.ratio` から取る（文字列を書き込まない。範囲試験が、3 つの関数に 25・100 の定数がないことを確かめる）。複数のルールが成立したときは `_profile_lines` と同じく `met[0]`（EXFEAR、NORMAL、TREND の順）。足さない朝（合図なし、F&G観測待ち、データ異常、観測記録の衝突、HALT、ERROR）は 1 行目も本文も変わらない。
