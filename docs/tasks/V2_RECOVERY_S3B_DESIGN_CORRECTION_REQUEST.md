- ACK／DECLARE_MISSING：新しい有効親のstate_afterと一致。

### N-02 MIGRATIONが無い場合の復元点

D-2の推奨を条件付きで明確にする。

- 移行履歴にMIGRATIONがある場合：復元点はそのMIGRATION自身または以後の適法な点。
- MIGRATIONの無い新規v2履歴：GENESISが下限。
- 有効履歴内の点だけ、直前は不可、requestバッチの途中は不可、という条件は両方で維持。

§5.3、§8.1、§14のD-2、依頼の対応箇所にそろえる。例RはMIGRATIONなし・現在のseqのまま受理する。H-04〜H-06に、新規v2でGENESISへの復元を許す正例と、移行履歴でMIGRATION前を拒否する負例を対応させる。意味のない移行記録を例Rに足して回避しない。
