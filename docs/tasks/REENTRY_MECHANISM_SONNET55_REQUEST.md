## 問い

## 出力して確かめること

1. 最初の売却以前はRの違いで経路が変わらないことを確認。違う場合は不具合として止める。
2. NORMAL/EXFEARを**合図日Dとイベント種別で**揃え、Rごとに以下を比較：
   - Dと次回代理約定日、既存株数/現金/平均原価、買増株数/支出、買増後原価
   - R100で買増が0/1株になる件数と現金。0は余力不足と区別し、欠損データで0を作らない
   - 次の利確合図/代理売却日、20%/RSI75の内訳、D終値利益率とOpen実現利益率、税/費用
   - 売却後に次の実際の購入まで待機したセッション数
3. とくに2026-02-09再エントリー、3/09通常買い、3/12と4/09・4/13の売却に対応する局面が、何開始で**同じ暦日**に繰り返されるか。遅延1で該当しない場合も報告し、別日を都合よく選ばない。
4. 同じイベントの反復を除いたユニークな市場局面数を、遅延別に示す。定義は「合図日D＋NORMAL/EXFEAR等の種類」。Rや口座開始が違うだけで別の独立相場に数えない。遅延0/1の異なる合図も独立標本とはしない。
5. 参照R25との差を現金/株時価/未収などへ照合。過去の待機中の株価上昇を説明に使っても、当時知っていた判断材料に混ぜない。途中寄与を重複加算しない。

主2開始・遅延0の既存6経路は必要時に5f2593eのevent_comparisonから**再利用だけ**。再実行せず、24追加と区別する。I0/100、NO_SELL、P20_ONLYの既存結果は保持し、今回の固定24に無いから候補から除外しない。
