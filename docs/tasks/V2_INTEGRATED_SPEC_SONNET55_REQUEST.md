## 統合すべき内容

### A. 共通市場状態と口座条件の分離

SOXX/SHD/F&G/armed/連続数/normal_rawの共通計算と、候補別の口座/売却歴/待機を分ける。
研究では両プロファイルの口座経路が変わる。NO_SELLへP20の全売却履歴や原価を渡さない。同じ実装を共有することを同じ口座状態であることと混同しない。

「NO_SELLは売却条件を省いたプロファイル」と記載できるが、追加工数が小さいという未計測保証はしない。
