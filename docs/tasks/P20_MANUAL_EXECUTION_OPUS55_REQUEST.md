## 具体化する2点

### 1. 手動売却の損切り禁止が成立する条件

- P20合図：実保有株数×D終値÷買付費用込み原価−1>=20%。翌Openの実現利益20%を意味しない。既存研究のDでの費用後2%候補ゲート/翌Open事後2%ゲートも、そのまま採用済の実運用下限へ移さない。
- 売却の必要条件：売却部分に帰属する費用込み原価B_k、実現売却代金から該当費用C_kを差し引いた額、設定税を区別する。固定為替150/税20.315%のモデル条件は変えない。実口座の課税区分は本人確認前に確定しない。
- 全量1回なら n*p-C(n,p,d)>=B*(1+g)。gは未採用の追加利益条件で、2%を勝手に決めない。損失を出さない境界（g=0を置いた数学的例）と、別途正の利益を求める方針を分ける。g=0の例も新戦略の採用ではない。
- 価格依存費用、最低単位/端数、売却側諸費用を確認し、有効な刻み価格での下限を定義できるか示す。円建て税務や新しい為替モデルを追加しない。
- 一部約定、複数日にわたる約定、取消後の出し直しで、費用の集約単位・原価配分・丸めが変わる可能性を調べる。全量の上限費用を単純に1株あたりへ按分して、任意の部分約定でも保証できるとしない。
- 原価配分の内部計算、楽天が税務上記録する原価、約定報告の費用を同一と決めつけない。確定値が未入手ならどの判断ができないかを具体化する。
- 指値なら損切り禁止を無条件に保証するという結論は禁止。確認できた手数料・原価条件のもとで成立する条件を示す。最低価格を満たさない、乖離で受付不可、部分約定、取消依頼中、当日失効、企業行動時を区分する。
- 日足だけでは指値の実約定/約定順序はわからない。不成立なら保有継続し、研究の事後ゲートと別経路になる。再エントリーは全売却の実約定確認後にだけ始め、一部売却中は0株扱いしない。
- 無条件成行、逆指値による損切り、損失確定の終端強制売却は追加しない。買付は既存の次回寄付き手動のまま。

### 2. 朝の通知と夜の手動確認の最小契約
