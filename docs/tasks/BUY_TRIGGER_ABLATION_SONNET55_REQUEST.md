## 4. 研究用コピーの変更範囲

元engine.mjsを新フォルダへコピーし、enableNormal/enableExFear（どちらも省略時true）を追加する。型を検査し、不正値は失敗させる。変更は市場条件が成立した後の**pending買い注文の選択**だけに限定する。

- enableNormal=false：NORMALの注文を作らない。
- enableExFear=false：EXFEARの注文を作らない。
- signals()の値・通常買いの立上がり履歴・恐怖状態の消費/再武装は変えない。EXFEAR注文を外しても、その日の市場側のarmed消費は元どおり。
- 売却の優先順位、初回トレンド参加、売却後再エントリーの条件/I/R/クールダウン、売却ゲート、会計を変えない。元コードと同じ初回/再エントリー判断を残す。
- 初回・再エントリー機能はONのままだが、保有経路の変化により実際の発生回数は変わり得る。「通常買いOFF」を「通常相場で一切購入しない」と言い換えない。
- 市場シグナルと、抑止された注文、余力不足、約定を説明出力で区別する。candidatesのpendingは選択した注文を正しく表す。
- cfgの新フラグを除く元の返却項目・計算を変えない。不要なリファクタリングはしない。

OFFにより、その後の売却日・再投資余力等も変わる。差額をその買い条件だけの加法的な利益寄与や統計的因果効果と呼ばない。仕様がこの限定変更では実装できない場合は拡張せず主担当へ戻す。
