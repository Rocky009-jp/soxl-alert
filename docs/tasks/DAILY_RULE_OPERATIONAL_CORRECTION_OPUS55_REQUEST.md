## 修正範囲：DO-01〜06のみ

### 1. 推奨理由と研究/観測時刻（DO-01/02）

§7-1を上記事実へ修正。I25を比較基準として挙げる理由と、資産最大化で一貫した最良という主張を分ける。I0/I100を操作負荷やDDで除外しない。最良未確定を残し、比率探索を再開しない。

朝1回のF&G記録はユーザーの簡素な運用に合う提案とする。履歴as-of未検証なので「遅延0に最も近い」とは断言しない。実際の観測日時と対象セッションDの対応、当日のdecision行を固定する時点を記す。

### 2. 市場状態の未知と再実行（DO-03）

§3/4/6を整合させる。朝の目視前は当日のarmed/streak/normal_raw更新結果を確定しない。「前日も目視」は過去の観測を新規に作る表現を避け、保存済みの前日観測があれば使い、なければ不明とする。

欠測日は連続数を途切れさせる案と、「欠測日にEXFEAR消費が起きた可能性が不明」なことは別。少なくとも次を短い状態表で示す：
- 未観測の当日、前日状態不明、履歴proxy由来の仮状態、実観測で確認した状態。
- F&G≥30が3セッション連続で観測できた場合の再武装。
- 前日normal_rawが不明な翌日の通常買い立上がりの確定可否。
- 同じDのdecision確定後の再実行で、連続数/episodeを二重更新しない扱い。

不明をfalseや既知の0へ置換せず、履歴proxyの仮状態から確定売買候補を出してよいかは明示的な判断項目にする。未承認の間は参考/未確認として表示。状態が不明でも、関係のない情報まで一律停止する要件は追加しない。厳密なコード/永続化実装は作らない。

### 3. 売却と注文/保有状態（DO-04/05）

§5の式を、全量研究モデルの必要条件として次の形に改める：
n×p−C(n,p,d)≥B×(1+g)、pは適用可能な価格刻み。
n=実株数、B=費用込み原価、C=価格/数量/日付に依存する売却費用、g=未採用の最低利益率。単純な右辺代入で決まる価格、または全ての実注文で保証する価格とは書かない。

研究saleFloorは全株一度のモデル。実際の一部約定では、売却した数量に帰属する原価・確定費用・残りの原価、日跨ぎの手数料集約/端数が必要。全株分の上限費用の単純均等割当だけで保証できた扱いにしない。仕様/公式根拠が不足なら具体的な価格計算とP20の実行可能性を保留し、その依存関係を§7にも反映する。2%を正式な最低利益へ採用しない。

保有更新日時と、本人が状態を確認した日時を分ける。売買がないだけで原価が変わるわけではない一方、未確認の約定・未約定注文・CA/分配・MMF/資金拘束を無視しない。必要項目は株数/原価/実際に利用可能な資金/未約定残/注文状態/確認日時。入力先はまだ選ばない。

§6-4を「全額保有だから余力なし」と断定しない形に修正。余力不足は確認されたときだけとし、不明なら要確認。部分売却は全売却後の再エントリー状態にしない。

残る指値を翌朝再判定する場合は、当日失効/取消完了等により旧注文の状態が確認できているかを示す。取消依頼中を取消完了とみなさず、同じ保有へ二重の新注文を案内しない。日足判定と夜の手動注文という運用を維持。

部分約定/日跨ぎの集約単位・全端数処理・ユーザー設定は確認未了。再確認が必要なら公式公開一次資料だけを最小限読む。口座ログイン/注文/API登録・市場データ取得はしない。既存研究の費用/入力は差し替えない。
