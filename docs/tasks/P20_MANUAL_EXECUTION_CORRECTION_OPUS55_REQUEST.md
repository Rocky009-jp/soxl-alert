## PM-01：費用上界の主張を限定

E1/E2の総手数料率と上限だけから、任意の部分約定に帰属するC_k<=rho*k*q+0.02は導けない。A1〜A5には費用帰属方法がなく、丸めの回数/項目数等も未確認。
主担当の100株・40.23・集約費用20.01を最初の1株へ配分する反例は、実務の事実ではなく未指定配分の論理例。事実誤認として退けず、不足仮定を特定する。

- 全量合計の損益、各約定部分の経済的損益、税務上/画面上の損益を分ける。
- 追加仮定で式を保持するなら、費用の集約・帰属/丸め/追加費用の条件を十分に明記した**数学上の条件付き参考例**に隔離する。実務未確認で「どんな分け方でも頑健」と表現しない。
- 不足事項が未確認なら、数値下限や実注文候補を保留したままで修正完了としてよい。0.02を別の定数へ増やして保証を主張しない。
- 未来の課金方法や楽天の仕様を仮定で補わない。公式事実の新規調査を網羅的に増やす必要はない。追加公式読取は不可欠な場合だけ最大2ページ、取得不能なら保留にする。

必要な事実が未確認/変更検知/失効した時点でS3停止。前提が崩れたと判明するまでは有効というデフォルトにしない。

## PM-03：0株と全売却を区別

B/nおよびb*との比較は、確認済n>0かつB>0/有限のときだけ。
確認済0株は「売却対象なし」。未入力/古い保有、不正な株数/原価、企業行動要確認と分ける。
0株の事実だけでは全売却確認済/再エントリー待機起点にしない。実際の戦略上の全売却約定履歴と注文残/取消・訂正の確認を要件にする。新規0株や移管等を全売却歴へ変換しない。
