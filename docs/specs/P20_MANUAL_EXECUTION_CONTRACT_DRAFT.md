## 1. 結論と成立条件

1. **P20合図**は「実保有株数n×D終値÷費用込み原価B−1≥20%」で、1株あたり原価b＝B/nを使うと「b≤D終値÷1.2」と同じ。これは朝に確定日足だけで判定できる。翌Openでの実現利益20%や、研究の2%ゲートの成立を意味しない。
2. **売却で損失を出さないための十分条件（推論）**
   - 指値Lが次を満たせば、§3の前提A1〜A5の下で、どの数量・どの分け方で約定しても、売った分の売却代金−売却費用が、その分の原価×(1+g)以上になる。
   - 式：`L ≥ ceil_cent((b×(1+g) + 0.02) ÷ (1 − 0.00495 − 0.0000206))`
   - 楽天が保証する性質ではない。前提が崩れれば成り立たない。
3. **より厳しい制約は、楽天の指値の受付範囲**
   - 売り指値は、基準価格から一定幅（50ドル超は−3%、25〜50ドルは−5%、25ドル以下は−10%）より下には置けない。
   - P20合図の日は、通常、D終値が原価の1.2倍以上ある。そのため、受け付けられる最も低い指値でも、損益分岐の下限より上になりやすい。
   - 逆に、受付範囲の下限付近の指値は、寄付き後に価格が上がると失効し得る（楽天の記載）。
4. **日足では指値の約定・不成立・約定の順序が分からない。** 不成立なら保有を続ける。研究の「翌Openで事後2%ゲート」とは別の経路になる。
   - 既存のP20_ONLY I25/R25の主2開始の経路では、8回の売却のうち3回（2026-01-07、07-01、08-05）で、翌Openが受付下限（D終値の97%）を下回っていた。両開始で同じ日付で、独立した3事例ではない。
   - 出典は5f2593eのevent_comparison.csvの既存の値。
   - したがって、研究の損益を手動指値運用の見込みとして使えない。
5. **gは未採用。** g=0は損益分岐の数学的な例で、新しい戦略の採用ではない。研究の2%を実運用の下限へ移さない。正のgを求めるかは利用者の判断（§7-1）。
6. 無条件の成行売り、逆指値による損切り、終端での損失確定の強制売却は追加しない。買付は朝の確定日足判定→次回開場での手動購入のまま。

## 3. 数式と適用範囲

記号：n＝確認済みの実保有株数、B＝費用込み原価（USD）、b＝B/n、g＝未採用の追加利益率（g≥0）、ρ＝0.00495＋0.0000206＝0.0049706（E1・E2、確認日時点）。

**(a) 全量を1回で約定するモデル（既存§5）**：`n×p − C(n,p,d) ≥ B×(1+g)`。C(n,p,d)は端数処理を含めて確定しないと正確に計算できない（E3）。参考の式にとどめる。

**(b) 一部約定と合算単位に頑健な十分条件（本書の提案）**

- 割当の約束（モデル上の定義）：k株を売った分の原価をB_k＝b×kとする（平均原価）。楽天や税務上の取得価額と同じとは決めつけない（E10）。
- I1により、価格q≥Lでk株が約定すると、`k×q − C_k ≥ k×q×(1−ρ) − 0.02`。
- これが`k×b×(1+g)`以上になる条件は、k=1が最も厳しく、`q ≥ (b×(1+g)+0.02)/(1−ρ)`。
- q≥L（I2）なので、Lをこの値以上の刻み価格に切り上げれば十分になる。これを L_floor と呼ぶ。
- 数値例（仮定値で、実口座ではない）：b＝40.00、g＝0のとき、(40.02)/0.9950294＝40.2199… → L_floor＝40.23。

**前提（どれか1つが崩れれば保証しない）**

- A1：手数料・SEC Feeが、E1・E2の料率と上限の式で、約定ごとかそれより大きい単位で計算される。項目ごとの端数は1セント以内。
- A2：USD決済で、売却時の現地費用がE1・E2以外にない。円貨決済の為替手数料（25銭）は対象外。
- A3：原価の割当はB_k＝b×k（平均原価）。
- A4：約定価格は指値以上（E8の訂正を含む）。
- A5：料率は約定日時点の値を使う。改定されたら計算し直す。

**適用範囲の外**

- 円建ての税務（為替差損益、取得価額の円換算）。USDで損益分岐を満たしても、円建てで損失にならないとは言えない。研究の150円固定・20.315%は変えない。
- 企業行動（分割など）でn・bが変わった場合。
- 約定の取消・訂正で数量が変わった場合（再確認するまで「要確認」）。

**受付範囲との関係**

- 置ける指値は L ≥ L_floor かつ L ≥ ceil_cent(基準価格×(1−幅))（E6）。
- 時間外は基準価格＝前日終値（多くはD終値）、取引時間内はNBB。
- 基準価格×(1−幅) < L_floor（相場が損益分岐近くまで下がった）なら、L_floor以上の指値は受け付けられる。ただし約定しにくくなる。
- 実際の基準価格が L_floor÷(1−幅) を下回るほど下がっても、L_floor未満には置かない。不成立を受け入れて保有を続ける。
