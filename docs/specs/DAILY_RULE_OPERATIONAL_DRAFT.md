## 2. ルール表（研究engine.mjsからの転記）

市場状態は口座に依存しない（signals）。口座状態は保有・原価・現金・売却歴。F&Gは研究ではfg_used（遅延0はDの履歴値、遅延1はD−1）、実運用では目視値。

|---|---|---|---|---|
| 極端恐怖（EXFEAR） | F&G＜25かつarmed | 不問（保有中でも追加） | 成立でarmed＝false。F&G≥30が3セッション連続で再武装。研究では、F&G欠測日に連続数を0に戻す | 現金の100% |
| 通常買い（NORMAL） | normal_raw(D)＝25以上30未満のF&G、SOXX調整後終値＞SMA200、SOXX RSI14（Wilder）≤55、SHD（SPY 20日騰落率−IEF 20日騰落率）＜0。合図はnormal_raw(D)かつ**normal_raw(D−1)でない**こと（立上がり）に加え、DでarmedかつEXFEARでないこと | 不問 | armedは外さない。立上がりの比較はnormal_rawどうしで、armedは含まない。研究では、F&G欠測日のnormal_rawを不成立とする | 現金の100% |

| P20利確合図 | —（P20_OR_R75ではSOXX RSI≥75も） | 保有株数×D終値÷費用込み原価−1≥20%（手数料なし）、かつD終値での費用控除後利益≥原価の2% | 全株のみ。条件が続く限り毎日出る。F&Gに依存しない | — |

- 優先順位は売却＞EXFEAR／NORMAL＞初回・再エントリーで、1日に1件だけ。
- 合図日Dの次の取引セッションのOpenを、研究上の約定とする。
- 研究の事後ゲート：約定日のOpenで、費用控除後の売却益が原価の2%未満なら売らない（GATE_BLOCKED）。2%は税引前・費用控除後の値で、税は20.315%を売却益に課す。20%合図（D終値・手数料なしの含み益）、2%ゲート（Open・費用控除後）、税引後利益は別の量。

- **イベントの単位（DO-06）**
  - 買いの合図は、RSIの上抜け、normal_rawの立上がり、armedの消費という**その日のイベント**で決まる。同じイベントを翌日以降へ自動で持ち越さない。
  - 後日に新しい有効イベントが起きれば、別に判定する（例：RSIが55以下へ戻った後の再上抜け、normal_rawがいったん不成立になった後の再立上がり、再武装後のEXFEAR）。

| 段階 | 研究 | 実運用案 |

**観測時刻（DO-02）**：朝に1回、decision観測を記録する案。これは利用者の簡素な運用に合わせた時刻の案である。目視の現在値とDの履歴proxyは別の値で、履歴as-ofも未検証なので、研究の遅延0に近いとは言えない。

- **対象Dとの対応**：observed_at（タイムゾーン付き）の直前に通常取引を終えた米国セッションをDとする。休日・短縮取引・夏冬時間の扱いは、対象日の設計（未採用）に従う。
- **decision行の確定**：同じDについて、利用者が最初に「判断用」と記録した1行で確定する。後から追加した観測はsupplementalとし、判断を差し替えない。後日の履歴値で上書きしない。
- **夜の再確認**：夜に観測を判定へ使う案は変更案として扱い、採用済み要件にしない。
- **観測件数**：実観測は0件のままで、履歴as-ofの問題は解消していない。

### 3.1 市場状態の既知・不明（DO-03）

状態は3つ（armed、F&G≥30の連続数、前日normal_raw）。各状態を「確認済み」「仮状態」「不明」「当日未観測」に分ける。不明をfalse・0・不成立へ置き換えない。

| 区分 | 意味 | 合図の扱い（案） |
|---|---|---|
| 当日未観測 | Dのdecision観測がまだない | Dの更新を保留し、前日までの状態を示す。F&G依存の合図は「目視待ち」 |
| 確認済み | 保存したdecision観測から、規則どおりに決まる | 合図を通常どおり判定する |
| 仮状態 | 開始時に履歴proxyで作った値。または、確認済みの状態を前提に履歴proxyで補った値 | 合図は「参考・未確認」。確定候補にしてよいかは§7-3で判断 |
| 不明 | 欠測日があり、実際の値で状態がどう変わったか分からない | 合図は「参考・未確認」。関係のない合図は止めない（下記） |

| 場面 | 扱い（案） |
|---|---|
| armed確認済みで、欠測日があった | 実際にはその日に25未満でEXFEARが消費された可能性があり、armedは「不明」になる。連続数を0に戻す規則とは別の問題 |
| armedがfalse（確認済み）で、欠測日があった | 欠測日を≥30と数えないので、armedはfalseのまま。ただし、実際には再武装していた可能性は残る（不明の注記） |
| F&G≥30を、欠測を挟まず3セッション連続で観測した | 以前の状態にかかわらず、armedは「確認済みtrue」になる。不明・仮状態はここで解消する |
| F&Gが25未満を観測したが、armedが不明・仮状態 | EXFEARは「参考・未確認」。消費したかどうかの扱いは§7-3の判断に従う |
| D−1のnormal_rawが不明 | 不明になるのは、D−1の市場側の条件が成立していて、D−1のF&G観測がない場合だけ。市場側が不成立ならnormal_raw(D−1)は「確認済みの不成立」。不明のときはDの立上がりを確定せず、「参考・未確認」とする |
| 前日の観測 | 保存済みの前日decision観測があれば使う。なければ不明とし、後から過去の観測を作らない |
| 同じDを再実行した | D−1までの保存済みの状態と、Dのdecision行から計算し直す。更新済みの状態にもう一度Dを適用しない。連続数の加算とepisodeの消費は、Dごとに1回だけ記録する |
| 状態が不明な日 | P20の売却合図、初回・再エントリーの合図（armedや前日normal_rawに依存しない）、データ検査の結果は、通常どおり示す。全体を一律に止める要件は追加しない |

このための厳密なコードや永続化はまだ作らない。保守的な扱いで損益がどう変わるかは未評価。

## 5. 損切り禁止と実売却の境界（DO-04）

- **NO_SELL**：定期的な売却を発生させない。既存採用#4（売却推奨なし・過熱参考OFF）と矛盾しない。
- **P20**：朝はD終値での合図だけが分かり、次回のOpen・費用・約定は分からない。無条件の成行売りでは損失回避を保証できない（研究のGATE_BLOCKEDは事後判定）。
- **全量を1回で売るモデルの必要条件**：
  - 式は `n×p − C(n,p,d) ≥ B×(1+g)`。
  - n＝実保有株数、B＝費用込み原価、d＝約定日、g＝未採用の最低利益率。pは、適用される価格刻み（主担当の確認では原則1セント）の上の価格。
  - C(n,p,d)は手数料（従量・上限・端数処理）とSEC Feeで、価格・数量・日付に依存する。
  - このため、右辺を株数で割って代入するだけでは価格は決まらない。条件を満たす最小の刻み価格を探す形になる（研究のsaleFloorと同じ考え方）。
  - これは税引前・費用控除後の研究上の条件で、円建ての税務を含まない。
- **一部約定・日をまたぐ注文**：研究のsaleFloorは、全株を1回で売るモデルである。実際に一部だけ約定した場合は、次のものが要る。
  - 売った株数に帰属する原価B_kと、残りの原価B−B_k（配分方法は未確認）。
