# CNN Fear & Greed 観測記録ガイド

[空CSV](../templates/FG_OBSERVATION_TEMPLATE.csv)は、ユーザーが画面で目視した現在値と、実際の確認時刻を保存するための様式です。**実観測0件・未開始**。様式の作成はユーザーの参加・自動収集開始を意味しません。観測収集を待たず、別途固定データ比較を進められます。

1行を1回の観測とします。observed_at_iso8601はタイムゾーン付きISO8601（日本時間なら+09:00）。not_checkedでは観測値・観測時刻を空欄にし、0や前日値、現在の記入時刻で埋めません。対象米国取引日との対応が未確定ならtarget_us_session_dateも空欄にします。

observation_roleはdecision（実判断に使う観測）またはsupplemental（補助観測）。実判断用の時刻・役割は先に区別し、複数観測から後で都合のよい値を選ばず、それぞれ別行にします。statusはobserved／not_checked。source_urlには実際に目視したページを記録します。

区分は「25未満」「25以上30未満」「30以上」。後日の履歴値・参照日・取得時刻は専用欄へ記録し、原観測を上書きしません。履歴の参照日が当時の取得可能時刻を意味するわけではありません。

20取引日等は探索的記録の区切りです。閾値近傍の観測がなければ不足と報告し、不一致0件でも過去全体・将来の同等性を証明したとはしません。欠損時のarmed／連続リセット等の実運用仕様は、この様式では採用しません。

口座、残高、実名、認証値は記入しません。根拠：[Opusレビュー](../reviews/TRADING_RULE_REVIEW_OPUS55_RESULT.md)／[主担当回答](../reviews/TRADING_RULE_REVIEW_RESPONSE_20261026.md)。定型整理はLuna、判断・記載確認は6.1 Sol High。
