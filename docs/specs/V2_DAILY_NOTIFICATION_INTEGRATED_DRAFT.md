## 1. 要約

1. 初版は**案U**：ツールは実保有・費用込み原価・現金・買付余力を受け取らない。買いは利用可能資金に対する**比率だけ**を示し、株数・金額・余力の十分性は出さない。本人のP20成立・初回か再参加か・余力・0株かは、ツールでは確定せず手元で確認する。
2. **NO_SELL I25** と **P20_ONLY I25/R25** を並列に設計する。市場状態（SOXX、SHD、観測F&G、armed、連続数、normal_raw）と買い条件の関数は共通。候補ごとの口座状態（保有・原価・現金・全売却歴・待機）は共通にしない。NO_SELLは「売却条件を持たないプロファイル」であり、過熱RSIの売却はどちらにもない。追加工数が小さいという保証は、未計測のため置かない。
3. 比率は、通常買い・極端恐怖が利用可能資金の100%、初回参加・全売却後の再参加が25%。
4. P20の参考として、**b\* ＝ SOXLのD終値 ÷ 1.2**（費用込み1株平均原価の目安）を示す案。売却下限・指値・売却推奨ではない。b\*は**採用前の新しい参考出力**であり、本番へは送らない。
5. F&Gは、朝に目視した現在値を `value / observed_at（TZつき）/ target_session_date / decision か supplemental` で記録する。案Uでも、この入力と前日までの市場状態は必要。朝の観測が履歴の遅延0／1のどちらに近いかは決めない（履歴as-ofは未検証、実観測は0件）。
6. 毎回の完了サマリは既存の承認済み要件。「合図なし」「F&G観測待ち」「参考・未確認」「データ異常」「一部失敗」「通知失敗・配信不明」を判別できるようにする。
7. 回帰は**研究パリティ**（参照ハーネス）と**運用契約**（仮の入力・欠測・案Uの限界）に分ける。研究の株数・金額は参照ハーネスの照合にだけ使い、製品の数量要件にしない。
8. P20の研究損益（翌Open代理、事後2%ゲート、翌価格を知った数量等の診断前提）は、V2の手動注文（指値・不成立・部分約定）へ当てはめられない。
9. 実装前にユーザーが決める点は**3つ**（§9）。受入基準は**11項目**（§7）。

### 3.2 目視F&G観測（decision / supplemental）

[FG_OBSERVATION_GUIDE](FG_OBSERVATION_GUIDE.md)と[空CSVの様式](../templates/FG_OBSERVATION_TEMPLATE.csv)に従う。

| 項目 | 内容 |
|---|---|
| `current_fg_value` | 目視した現在値。`observation_status`＝observed のときだけ。not_checked では空欄（0や前日値で埋めない） |
| `observed_at_iso8601` | タイムゾーン付き（日本時間なら+09:00）。実際の確認時刻。記入時刻で代用しない |
| `target_us_session_date` | 判断の対象D。observed_at の直前に通常取引を終えた米国セッションとする案（運用ドラフト§3）。対応が確定しなければ空欄 |
| `observation_role` | decision（実判断に使う観測）／supplemental（補助）。同じDで最初に decision と記録した1行で判断を確定する。後から足した観測は supplemental で、判断を差し替えない |
| 履歴値の欄 | `historical_*` は後日の履歴proxy用。**原観測を上書きしない**。履歴の参照日が当時の取得可能時刻を意味するわけではない |

- **観測の位置づけ**：朝の目視値は、研究の遅延0（Dの履歴値）にも遅延1（D−1の履歴値）にも分類しない。観測の as-of は未検証で、実観測は0件。確認済みの架空履歴を作らない。
- **不足時**：decision行が無ければ、そのDの市場状態の更新は行わず、前日までの状態を示す。F&Gが要る条件は「F&G観測待ち」（§4.2）。観測後に再通知する、夜に再確認する、という要件は本書では追加しない（朝の通知の分岐表で手元判定できる、§5.2）。
- **再実行**：同じDの decision 行が既にあれば、それを使って計算し直す。同じDの観測を二重に数えない（§4.3）。

### 3.3 市場状態スナップショット（前日までの持ち越し）

案Uでも、市場状態の持ち越しは要る。口座情報を含まないが、保存先・更新責任・鮮度は未採用（§9-2）。

| 状態 | 値 | 区分 | 更新に使う入力 |
|---|---|---|---|
| armed | true／false | 確認済み／仮状態／不明／当日未観測 | decision観測（F&G＜25で消費、≥30の3連続で再武装） |
| F&G≥30の連続数 | 0以上の整数 | 同上 | decision観測（欠測日は数えず0に戻す、観測ベース） |
| 前日normal_raw | true／false | 同上 | 前日のF&G観測と前日の市場側条件 |

付随して `as_of_D`（どのDまで反映したか）と、更新に使った観測の `record_id` を持つ。口座・保有・原価の値は持たない。

実保有株数、費用込み原価、現金・MMF・利用可能USD、未約定注文、全売却歴、約定記録。**通知だけでこれらを更新しない。未知の保有を0株にしない。**

## 4. 判定と状態

### 4.1 F&Gを使わずに確定できる範囲

朝の通知時点でF&Gが未観測でも、市場側の必要条件が不成立なら、F&Gに関係なく不成立と確定できる。これは既存の運用ドラフトの区分と同じで、無関係な判定を一律に止めない。

| ルール | F&Gなしで不成立と確定できる場合 | F&G観測待ちになる場合 |
|---|---|---|
| EXFEAR | armedが**確認済みfalse**のとき（armedが不明・仮状態なら確定しない） | armedが確認済みtrue、または不明・仮状態 |
| NORMAL | D：SOXX≤SMA200、RSI14＞55、SHD≥0 のどれか。または D−1 のnormal_rawが確認済みtrue（立上がりでない）。または armedが確認済みfalse | 上記のどれでもない |
| トレンド参加 | SOXX≤SMA200、またはRSIが55を上抜けていない | 上記のどちらでもない |

- 市場側が全て不成立ならF&G未観測でも「合図なし」と確定してよい。一部でも成立の余地が残れば「F&G観測待ち」。
- EXFEARは市場側の条件がF&Gとarmedだけなので、armedが確認済みtrue／不明のとき、F&G未観測では不成立を確定できない。

### 4.2 実行区分

| 区分 | 意味 | 終了 |
|---|---|---|
| 合図なし | データ正常。市場側で全ルールが不成立と確定（F&G観測の有無を問わない、または観測済みで不成立） | 0 |
| F&G観測待ち | データ正常。市場側で成立の余地が残り、decision観測が無い。購入条件を確定しない | 0（本書の案。運用エラーではない） |
| 市場条件成立（確認済み） | decision観測あり、必要な状態が確認済みで、いずれかのルールの市場側条件が成立 | 0 |
| 参考・未確認 | 条件は成立するが、armed／連続数／前日normal_rawが仮状態・不明のため確定しない（§4.3） | 0 |
| データ異常 | Dの未確定、価格欠損、対象日不一致、履歴不足、指標の算出不能 | **1**（採用済み#2。通知の成否と無関係） |
| 一部失敗／通知失敗／配信不明 | Sheets書込失敗、通知のHTTP失敗、応答なし | 1（採用済み#2。配信不明は自動再送しない） |

「市場条件成立」は購入の決定ではない。口座条件・資金は手元で確認し、F&Gが未観測なら「購入条件確定」と表示しない。

### 4.3 市場状態の区分と扱い

[運用ドラフト§3.1](DAILY_RULE_OPERATIONAL_REVIEWED_DRAFT.md)の区分を、入力契約として整理する（未採用案）。不明・仮状態・当日未観測を、false・0・不成立へ置き換えない。

| 区分 | 意味 | 合図の扱い |
|---|---|---|
| 確認済み | 保存したdecision観測から規則どおりに決まる | 通常どおり判定 |
| 仮状態 | 開始時に履歴proxyで作った値、または確認済みの状態を前提に履歴で補った値 | 「参考・未確認」 |
| 不明 | 欠測日があり、実際の値で状態がどう変わったか分からない | 「参考・未確認」。無関係なルール（§4.1で確定できるもの）は止めない |
| 当日未観測 | Dのdecision観測がまだない | Dの更新を保留し、前日までの状態を示す。F&G依存は「観測待ち」 |

| 場面 | 扱い |
|---|---|
| 欠測日があった（armedが確認済みtrue／false） | どちらも**不明**にする（欠測日に25未満で消費された、または再武装した可能性がある）。連続数は0に戻す（観測ベース）。保守的な案で、損益は未評価 |
| F&G≥30を欠測なしで3セッション連続観測 | 以前の状態にかかわらずarmedは確認済みtrue。不明・仮状態はここで解消 |
| D−1のnormal_rawが不明 | 不明になるのは、D−1の市場側条件が成立し、かつD−1のF&G観測が無い場合だけ。市場側が不成立なら「確認済みの不成立」。不明ならDの立上がりを確定せず「参考・未確認」 |
| 前日のdecision観測が無い | 不明とする。後から過去の観測を作らない |
| 同じDの再実行 | D−1までの保存済み状態と、Dのdecision行から計算し直す。更新済みの状態にDを再適用しない。連続数の加算とepisode（armedの消費）はDごとに1回だけ記録 |
| 開始時の初期状態 | 案A（履歴proxyで仮状態）／案B（不明、3連続観測で確認）／案C（研究と同じ初期値）。どれを採るかは§9-2。決まるまで確認済みにしない |

**研究との差**：研究の`signals()`は、F&G欠測日に連続数を0へ戻し、normal_rawを不成立とするが、armedは変えない。運用契約は、欠測後のarmedを「不明」とする点で研究と異なる。この差は意図したもので、研究パリティ（A1）は欠測のない完全な履歴だけを対象にし、欠測時の挙動は運用契約（A4）で試験する。

## 5. 出力仕様

### 5.1 共通の約束

- 買いは利用可能資金に対する**比率だけ**（NORMAL／EXFEAR＝100%、初回／再参加＝25%）。株数・金額・買付余力の十分性・「資金不足」の断定を出さない。
- 本人のP20成立、初回か再参加か、0株か、全売却歴、待機中か、余力は**確定しない**。市場条件の成立と、口座条件付きの参考表示を区別する。初回と再参加が同時に本人へ成立したとは書かない。
- 売却推奨・緊急脱出・過熱参考通知・成行売り・数値の売却下限・指値水準を出さない（採用済み#4、およびF1〜F4未確認）。
- 自動発注・口座接続・約定／注文残の推定をしない。通知は保有・原価・売却日を更新しない。
- 日付・価格の例は仕様例で、実際の値ではない。

### 5.2 朝の通知の構成（案）

1. 見出し：実行区分（§4.2）、対象D、データの確認結果、（対象日設計が採用されたとき）次回開場の目安。
2. 市場側の条件：F&Gを除く各ルールの成立・不成立（§4.1の確定範囲）。
3. F&G：decision観測の値・observed_at・対象D。未記録なら「未記録（購入条件は未確定）」と、**F&Gの値による分岐表**（25未満／25以上30未満／30以上でどうなるか）。
4. 状態の区分（armed等）と、仮状態・不明があれば「参考・未確認」。
5. プロファイル別の口座条件と手元確認（§5.3）、P20の参考（§5.4）。
6. 実行サマリ（§6.2）。

### 5.3 プロファイル別の表示と手元確認

| 項目 | NO_SELL I25 | P20_ONLY I25/R25 |
|---|---|---|
| EXFEAR／NORMAL成立時 | 100%（比率のみ） | 同左（共通） |
| トレンド参加成立時 | 本人が0株の場合のみ25%。再参加は該当しない | 初回（0株・売却歴なし）または全売却後の再参加（約定から3セッション以上）のどちらに当たるか、またはどちらでもないかは**手元確認**。25% |
| 売却 | 条件なし | 本人のP20成立は未判定。売却優先の確認は手元。売却推奨は出さない |
| 手元確認の項目 | 保有株数、利用可能USD、未約定注文 | 左に加え、全売却歴、最後の全売却の約定セッション、費用込み1株原価 |

### 5.4 b\*（P20の原価目安、採用前の新参考出力）

- **定義**：b\* ＝ SOXLのD終値 ÷ 1.2。費用込みの1株平均原価bが、b≤b\* ならP20のD価格条件（保有株数n×D終値÷費用込み原価B−1≥20%、手数料なし）を満たす、という**原価の目安**。n>0かつB>0が確認済みのときだけ成り立つ式の言い換えである。
- **意味しないもの**：売却下限、指値、推奨売却価格、損失回避の水準、翌Openの約定、研究の2%ゲート（費用控除後）の成立、実現利益20%の保証。買値（手数料抜き）でもない。
- **丸め**：10進演算で`D÷1.2`を計算し、**セント未満を切り捨てて**2桁で表示する。切り捨てにより、「b≤表示b\*」と読んで成立と誤認することは起きない（境界付近では成立を見落とす側にずれる）。
- **境界の注意**：b\*の表示と原価の差が0.01未満のときは、表示だけで成立・不成立を断定せず、`n×D終値÷B−1≥0.20` を直接確認するよう注記する。目安の丸めで成立を断定しない。
- **数値例（算術のみ、市場の値ではない）**：D＝48.00 → 40.00（ちょうど）。D＝48.01 → 40.008333… → 表示40.00。D＝47.99 → 39.991666… → 表示39.99。
- 保有を渡さない案Uでは、「あなたのP20が成立」とは書かない。出力は「原価がこの値以下ならD価格条件を満たす」。
- b\*は新しい参考出力で、採用前。採用されても、本番へ送る前に別の承認が要る（採用済み#4の「売却推奨なし」との整合は§9-1で確認する）。

## 6. データ・実行の失敗区分と毎回サマリ

### 6.2 毎回の完了サマリ（既存の承認済み要件）

合図なしの日も含め、実行ごとに出す。次を判別できるようにする：合図なし／F&G観測待ち／市場条件成立／参考・未確認／データ異常／一部失敗（Sheets）／通知失敗／配信不明。
