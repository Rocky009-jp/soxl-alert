## 引き継ぐ留保

| 項目 | 主担当の整理 |
|---|---|
| 指標の同一性 | auto_adjust=TrueのCloseと、Falseで取得したAdj Closeの対応は、同じ応答・同じ履歴窓等を前提にする。候補のperiod=1yからN=260セッションへ変えるとRSIの初期化・開始日が変わり得る。「取得窓変更を含めても完全同一」とはまだいえない。系列の写像と窓変更を別に検証する |
| 推定予定時刻F | T以前の直近cronから逆算する方式には「遅延が次のcronより短い」という前提がある。24時間以上など次の一致時刻を越えた遅延は、event.schedule文字列だけから元の予定日を識別できない。予定日取得済み・全遅延を検出可能とはしない |
| Adj Close代用 | ライブラリ内部の黙認代用は、表にAdj Close列があるだけで検出できない。配当イベントと比率の疑い検査も、イベント欠落・窓境界・丸め等を含む検証が必要なヒューリスティックで、非代用の証明ではない |
| Sheets重複 | A列確認→追記だけでは同時実行間の競合を解消しない。既存行が旧価格定義である場合の扱いも必要。1行保証・既存シート互換確認済みとせず、運用判断と実装設計を残す |
