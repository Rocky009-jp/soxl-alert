## 主担当の補足（別名の未採用案）

原稿のS0b「B≤0」が確認済0株/B=0と重なるため、n>0のときだけ原価の正値条件を適用する。保有nが未確認ならS0a、n>0でB未入力もS0a。nが負/非整数/非有限、n>0で入力済Bが非正/非有限ならS0b。確認済0株はB/nを計算しない。未約定・取消/訂正・企業行動が未確認ならそちらの確認を優先し、0株だけで全売却としない。

§7-2は将来の夜の通常開場後の手動指値を検討案として残すが、F1〜F4未確認の今、受付下限だけで具体的指値/注文方式を採用しないと明示。

この4行だけを補足した別名コピーを docs/specs/P20_MANUAL_EXECUTION_REVIEWED_DRAFT.md に保存。原稿ブランチは変更しない。ルール採用や損益評価を追加したのではないため、Claudeへ再度全文修正を依頼しない。
