## 用語

- **D**：確定した米国通常セッション（日足）。合図はDの終値と、その時点で保存されている値で決まる。
- **次回セッション**：入力テープ上のDの次の取引日。研究ではその日の**Open**を代理約定価格にする（`execution_phase: daily_open_proxy`）。20経路の全270約定で「約定日＝Dの次の取引日」を確認（`verification.json`の`execution_is_next_session_after_signal`）。
- **朝に分かるもの**：Dの終値・SOXX RSI・SMA200・SHD、利用者が入力した保有株数・原価・売却歴・現金、利用者が目視したF&G。
- **朝に分からないもの**：次回Open、Openでの株数、Openでの売却益・税、注文が成立するかどうか。

## 1日の処理順（engine.mjs の順）

1. MMF日次発生（月替わりに税引後計上）→ 分配金の権利・支払日proxy。
2. 前日に出た合図（pending）を**当日Open**で執行：SELLは2%ゲートを当日Openで再判定、買いは当日Openで株数を決める。
3. 当日終値で、SELL → ExFear/NORMAL → 再エントリーの順に1件だけ次の合図を作る。
4. 日次評価（現金＋株時価＋MMF未計上税引後＋分配未収）。仮想清算は評価だけで売らない。

## 朝の判断／次回Openでの代理評価／事後ゲートの区別

| 層 | 研究での扱い | 実運用で同じか |
|---|---|---|
| 朝の判断（Dの確定値） | 合図・優先順位・armed・待機・D終値での利益率。保存テープからそのまま再現できる | 同じにできる。ただしF&Gは履歴proxyで、目視値・目視時刻は未決 |
| 次回Openでの代理約定 | 株数・約定価格・手数料・税をOpenで決める | **同じではない**。朝に株数は確定できない。20経路の2株以上の買い143件中、D終値で見積もった株数のほうが多いのは80件（Openが上に開いた日）。最大で58株多い（2026-07-29→30、Openギャップ+16.7%） |
| 事後2%ゲート | OpenがD終値から下に開いても、Openで費用控除後2%以上なら成立 | **同じではない**。無条件の成行売りでは損失回避を保証しない。指値下限（`saleFloor`）は朝に計算できるが、楽天の指値制限・失効は未モデル化 |

今回の20経路では、SELL合図109件のうち**GATE_BLOCKEDは0件**。ただしD終値時点の費用控除後利益とOpenでの実現利益率の差が5ポイント超下がった売却が23件あり、最大は2026-06-30→07-01（D終値で+23.1%、Open約定では+9.7%、Openギャップ−10.8%）。朝に「+23%」と見えても、成立額は小さくなり得る。

## F&Gの扱い

F&G履歴値はas-of未検証のproxy。遅延1は「D−1の値しか使えない」という仮定のストレスで、実観測ではない。実運用は利用者の目視値を使い、目視時刻・夜の再確認は未決。ExFearの再武装には**合図がない日も含めたF&Gの連続記録**（≥30が3セッション）が要るため、目視運用では毎セッションの記録が必要になる。自動取得や確定値への置き換えはしていない。
