# SOXL 利確条件比較

SOXL_Exit_Comparison_2026-10-23.md が日本語報告書です。720条件の中心試算と480条件の感度試験を収録。全て日足の理想始値による診断で、実際の成行約定の成績ではありません。

Node.js 22以降で node run_exit_study.mjs。固定data/からresults/を再生成します。外部依存・ネット接続・口座接続は不要。

評価は未売却SOXL時価を含む最終総資産。summary.csvのliquidationが仮の全売却後評価です。含み損も資産に反映し、損切りを取引に追加していません。最大ドローダウンは順位に使っていません。
