# TQQQで同じ売買ルールを使った場合の試算（参考）

作成 2026-11-06。ブランチ `research/tqqq-same-rule-20261106`（基点 737ef35）。V2の実装ブランチや受領済みのものには触れていない。採用判断ではなく、診断目的の参考試算（DIAGNOSTIC_ONLY）。

## 結論

- 同じ期間（〜2026-08-10）、同じ会計で比べると、TQQQの最終額はSOXLの約半分になった（中央値 0.47〜0.49倍、範囲 0.28〜0.83倍）。72通りの組み合わせのうち、TQQQがSOXLを上回ったものは1つもない。
- 差の大半はルールではなく相場から来ている。同じ期間にSOXLは2024-10-01の始値から3.55倍、TQQQは2.04倍だった。2025-04の安値から見ると、SOXLは8.3倍、TQQQは2.6倍。
- TQQQでは、売らない（NO_SELL）版が20%利確（P20）版をほぼいつも上回った。SOXX指標そのまま版で12通り中10通り、QQQ置き換え版では12通りすべて。SOXLでP20が勝つことがある（12通り中5通り）のは、SOXL特有の大きな値動きによるところが大きい。
- SOXXの指標をQQQに置き換えても、TQQQの結果はほとんど変わらない（中央値 1.02倍、範囲 0.92〜1.29倍）。結論はどちらの読み方でも同じ。

## どちらの読み方が妥当か

- **基本（SOXX指標そのまま）** は、ルールを文字どおり使う読み方。買いの条件（SOXXの200日移動平均と14日RSI）と売りのRSI75に、半導体の指数を使い続ける。売買するのはTQQQだが、判断は半導体の相場で行うことになる。
- **参考（QQQに置き換え）** は、ルールの考え方（売買する商品の元の指数で地合いを見る）をTQQQに当てはめる読み方。F&GとSPY−IEFは市場全体の指標なので、そのまま使っている。
- 実際にTQQQを運用するなら、筋が通るのは**QQQに置き換えた読み方**だと考える。ただし、しきい値（RSI55、RSI75、F&Gの25・30、利確20%）はもともとSOXL・SOXXの期間で選んだもので、QQQ向けに検証したものではない。どちらの読み方でも結論（TQQQはSOXLの約半分、売らない版が優位）は変わらないので、この試算ではどちらを選ぶかは重要でない。
- 補足として、SOXLを売買しながら指標だけQQQにした組み合わせも試した。P20の経路ではSOXLの結果が大きく下がった（2024-10開始・遅れ0日で 44,682 → 18,185）。SOXLの売買ルールは、SOXXの指標と組み合わせて初めて今の成績になっている、と読める。

## 条件（SOXLの既存結果と同じ）

- エンジンは `research/SOXL_allocation_separation_20261026/engine.mjs` を無変更で使用。オプションは 77bb44f / 737ef35 と同じ：翌日の寄付きで約定、整数株、楽天の手数料・SEC費用、税20.315%、待機資金はMMF年3%、売却ゲート（費用控除後+2%以上）、損切りなし、1ドル150円。
- 入力は保存済みのYahoo日足 `research/SOXL_exit_study_20261023/data/daily.json`。TQQQのOHLCV（2024-10-01以降、分割調整済み）とQQQの調整後終値が、もともとこのファイルに入っていた。新しくデータは取得していない。Alpacaも使っていない。
- 変えたのは2点だけ。売買する商品をSOXL→TQQQにしたこと、参考版で指標の指数をSOXX→QQQにしたこと。F&GとSPY−IEFは変えていない。
- TQQQの分配金は、保存済みのYahooの権利落ち日の金額を使った。金額は調整後終値から逆算した値と全8回で一致している。支払日はProSharesの公表日を取得していないため、権利落ち日から7日後以降の最初の取引日で代用した。分配金は年に1%前後と小さい。
- TQQQは2025-11-20に2対1の株式分割があった。分割調整済みの価格で計算しているため、分割前の整数株の丸めがわずかにずれる（影響は1株分の価格以下）。

- 開始日どうしは期間が重なっているので、独立した標本ではない。
